# Figma – Wireframes and Auto Layout

## Objective

Create a functional, low-detail wireframe and use Auto Layout to organize related elements. A wireframe explores layout, content priority, and the route through a task, so it does not need final colors or visual effects.

## Connection to the course

> [!note] Key idea
> Choose a screen where accessibility matters particularly, such as a form or error state. Use Auto Layout to arrange the label, field, help text, and error message so related information stays together and text has enough room.

## Why is a wireframe more than “just a sketch”?

A **wireframe** is a deliberately simple screen sketch. It lets you check what users see first, which question each piece of information answers, and the order in which they can perform a task. Leaving out final colors, fonts, and illustrations keeps discussion focused on layout and behavior. A low-fi, or low-fidelity, wireframe is easy to change, making it particularly suitable for early testing.

**Auto Layout** arranges elements inside a frame according to rules. You can specify whether child elements run vertically or horizontally, the spacing between them, and how they behave when they contain more text. This is especially important for accessible interfaces: longer labels, larger text, and error messages should not obscure other content. Auto Layout does not automatically fix poor information hierarchy, but it helps preserve a good structure consistently.

## Terms

**Wireframe:** a low-detail screen sketch showing function and layout.  
**Low-fi:** a design with few visual details that can be changed quickly.  
**Auto Layout:** Figma's layout system for managing direction, spacing, and sizing rules between elements.  
**Content-based sizing:** an element's dimensions adapt to the text or content inside it.
