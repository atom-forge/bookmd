# Assignment – Refinement, UI guidelines, and usability testing

Refine the prototype based on feedback and begin deliberately developing its visual language. Check changes through brief, task-focused usability tests.

## Deliverables

- A shareable Figma link to the updated prototype;
- Mini UI guidelines: core colors, text styles, and relevant rules for buttons, inputs, and icons;
- The goals, tasks, and anonymized observation notes of at least three short usability tests;
- Findings ranked by severity;
- Justification of the selected improvements, specifically explaining how they make the main task more understandable or accessible.

Visual decisions must support task completion. Do not change things solely based on taste: reference observations or previous feedback wherever possible.
