# Assignment – Information architecture

Plan the screens and functions that make up your selected solution. The structure should support the persona's main task; do not try to cover the entire imagined product.

## Deliverables

- A shareable FigJam link;
- A list of main screens and the functions they support;
- A sitemap showing screen hierarchy and relationships;
- A visual structure of the core functions with clear labels;
- A brief indication of which elements will move into Figma from next week.

The sitemap should show how users reach their main task. Do not include irrelevant functions merely to match examples.
