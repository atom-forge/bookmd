# Figma – Visual hierarchy, typography, and icons

## Objective

Learn to arrange content so users quickly recognize the screen's purpose, important information, and next step. Font size, weight, spacing, color, and icons together determine visual weight.

## Connection to the course

> [!note] Key idea
> Create a screen or card presenting a project brief. Emphasize the user problem, main goal, and measurable success criterion; keep secondary details less prominent. Create at least two text styles and use only icons whose meaning is clear even without text.

## Guiding the eye

**Visual hierarchy** determines the order in which users perceive screen elements. The main heading is usually larger or heavier, the primary action stands apart, and supporting details have less visual weight. Hierarchy comes from more than font size: spacing, alignment, contrast, and empty space also communicate relationships and importance. If everything is emphasized, nothing is.

**Typography** is the deliberate use of text form and a system of text styles. Create recurring styles, such as a main heading, subheading, and body text. This keeps the interface consistent and later lets you change all text with the same role through one decision. An **icon** works well when it supports quick recognition; for important or ambiguous actions, it should not replace the text label.

## Terms

**Visual hierarchy:** the system for directing attention on a screen.  
**Visual weight:** the degree to which an element attracts attention.  
**Typographic style:** a reusable set of predefined text properties.  
**Contrast:** a perceptible difference between elements, such as size, color, or weight.
