# Assignment – Components, organization, and iteration

Organize recurring elements of the increasingly finalized interface into Figma components and build a small, usable design system. The system should reflect significant improvements made from the previous milestone's tests.

## Deliverables

- A shareable Figma link;
- A separate, clearly organized page or frame for the mini design system;
- Reusable buttons in at least primary, secondary, and disabled forms;
- Input fields in default, focus, and error states;
- Other relevant elements, such as checkboxes, radio buttons, or dropdown fields;
- Variants for relevant states;
- A brief decision log of significant iterations: evidence, change, and open question.

Create only components that actually occur on your project's screens. Keep naming and grouping consistent so the system can be reused on other screens.
