# Figma – Interface and UI elements

## Objective

Learn the basics of Figma's interface, the Layers and Pages panels, and the role of frames. Create a simple button, input field, and label while keeping layer names and relationships easy to follow.

## Connection to the course

> [!note] Key idea
> Turn a research insight into a very simple interface fragment: for example, a form field or selection control that helps participants provide information. At this stage, clear structure and an observable assumption matter more than a finished visual style.

## Figma's basic structure

A Figma file can be divided into **pages**. Consider separate pages for sketches, more developed screens, and reusable elements. Within a page, a **layer** is any independent element: text, a shape, an image, or another container. Descriptive layer names, such as “Search label” or “Submit button,” help both your future self and teammates find their way around.

A **frame** is a container that can represent a screen, a coherent section, or a component state. Always start a mobile screen in a frame so you can set its size, manage its contents, and connect it to a prototype later. A **group** simply moves elements together; it is not the same as a screen or layout system. When one element sits inside another, they have a parent–child relationship: the outer frame is the parent, and the label or icon inside is the child.

## Terms

**Page:** a separate workspace within a Figma file.  
**Layer:** an independently editable element or container.  
**Frame:** a container with dimensions and its own content, often the basis of a screen or component.  
**UI element:** a usable building block of an interface, such as a button, field, label, or icon.
