# Glossary

**Accessibility:** ensuring that a service can be used by people with different abilities, devices, and circumstances.  
**Affordance:** an interface cue indicating how an element can be used.  
**Insight:** an evidence-based understanding that leads to a design implication.  
**Iteration:** a deliberate change to a design based on new evidence.  
**Mental model:** the user's understanding of how a system works.  
**Persona:** a description of a target user derived from research patterns to support decisions.  
**Prototype:** a testable model of a proposed solution.  
**Success criterion:** an observable indication of whether the user has achieved their goal.  
**User flow:** the sequence of steps, decisions, and states leading to task completion.  
**Wireframe:** a low-detail screen sketch showing the structure and hierarchy of an interface.
