# Mi a web?

Az első fejezet a web jelentőségéből indul ki, majd történeti fejlődését, fő szereplőit, kliens–szerver modelljét és nyílt szabványait egy közös rendszer részeként tárgyalja. Az internet és a web különbsége a fejezet bevezetésében jelenik meg.
