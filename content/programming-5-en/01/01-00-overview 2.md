# 01 — What must the system do?

An idea for a shared task manager is not yet a system design. First we clarify user goals, the initial scope, and the meaning of stored data. Anna is a project owner and Jack a member. We follow these same actors and data throughout the course.

By the end, we can describe successful and failed use cases, identify business rules, and distinguish functions, quality expectations, and technical choices. These become the inputs for the working version in the next part.
