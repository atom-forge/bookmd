# 09 – WebSocket alternatives and selection criteria

Real-time interfaces can use several communication models. Polling, long polling, SSE, and HTTP streaming can satisfy simpler requirements; WebTransport and WebRTC offer different stream and connection capabilities. Socket.IO provides a higher-level protocol with its own client and server tools.


- [09.01. Polling and long polling](09-01-polling-long-polling.md) — periodic retrieval and HTTP requests held open for updates.
- [09.02. Server-Sent Events and HTTP streaming](09-02-sse-and-http-streaming.md) — one-way event streams and continuation.
- [09.03. WebTransport and WebRTC DataChannel](09-03-webtransport-and-webrtc.md) — streams, datagrams, and peer connection models.
- [09.04. Socket.IO and a comparison of real-time solutions](09-04-realtime-selection.md) — higher-level protocols and choosing a real-time communication solution.
